## 🔧 Going Deeper With Each Tool

### 🔁 Account Switcher

Useful if you keep a personal account and a work account, or if you share a computer. The switcher remembers each account separately, so your preferences, history, and settings stay attached to the right profile. Switching does not delete anything.

### 🧠 Custom Model Gateway

This tool lets you point Antigravity at a different model backend. You provide the connection details once and the app stores them safely on your own computer. Nothing is sent anywhere except to the endpoint you specify.

### 🖼️ Preview Browser

The preview panel behaves like a lightweight browser. Refresh it, resize it, or pop it out into its own window. It is especially handy when you are generating pages and want to see results without leaving your workspace.

### 📁 File Explorer

Your project files appear in a tree you can expand and collapse. Double-click a file to open it, right-click for more options. Long folder names are truncated neatly rather than pushing everything off screen.

### 🐙 GitHub Workspace

Connect your GitHub account once and your repositories appear in a searchable list. You can open a repository, check recent activity, and jump straight to the relevant page in your browser. It keeps your coding life and your AI work in the same place.

### 📊 Token Monitor

Numbers update live while you work. You can view usage for the current session, the current day, or a longer window. A subtle colour change warns you when you are approaching a limit.

## ❓ Troubleshooting

**The app will not open.** Close it completely from the taskbar or Task Manager, then open it again. A second attempt resolves most first-launch hiccups.

**Windows shows a security warning.** This is expected for newly downloaded software. Choose the option to keep and run the file.

**The window looks empty or blank.** Resize the window slightly or maximise it. This forces the interface to redraw.

**Account switching feels slow.** Make sure you are signed in to each account in your normal browser first. The switcher works best when it can see the accounts already present on your machine.

**Nothing happens when you click a download link.** Try a different browser, or copy the link and paste it into a new tab.
